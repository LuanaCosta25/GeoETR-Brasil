# GeoETR Brasil

Chatbot especializado em Elementos Terras Raras (ETR),
com foco no contexto brasileiro.

## Público-alvo

Pesquisadores, estudantes de graduação e pós-graduação
e profissionais dos setores mineral e ambiental.

## Objetivo

Disponibilizar informações técnico-científicas sobre
geologia, mineralogia, geoquímica, exploração, processamento,
aplicações tecnológicas e aspectos ambientais dos ETR.

## Tecnologias

- Python
- Llama.cpp
- Modelos de linguagem locais (GGUF)
- API compatível com OpenAI

## Estrutura do projeto

- dados/: bases de dados
- documentos/: artigos e documentos técnicos
- modelos/: modelos de linguagem
- src/: códigos-fonte do chatbot
